## How to read them

- **The mockups decide the look:** layout, spacing, hierarchy, colour and weight.
- **The specs decide behaviour and copy.** Where the two disagree, the spec wins. For example, `06-word-finder.html` says "Find word", but the button label is **"Find words"**.
- Glyphs such as ❝ ? ≈ ↻ [[ ✕ ✦ ☰ stand in for **Phosphor icons**. Use the Phosphor icon each spec names.
- The mockups use approximate hex values. Always use the real tokens from `src/global.css`.
- The mockup fonts are stand-ins. Use the site's real typography.
